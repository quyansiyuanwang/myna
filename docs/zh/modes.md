# 模式、上下文与权限

[返回主文档](../../README.zh-CN.md) · [配置项全表](config.md)

## 会话模式

模式按会话保存，标题栏的徽标可切换，⌘K 命令面板也可切换。

| 模式 | 适用场景 | 工具 |
|---|---|---|
| 普通 | 日常问答与本机操作 | 全部工具，按权限策略 |
| 计划 | 先调研、产出可执行计划 | 只读白名单；写文件、命令、鼠标键盘、自我修改全部拒绝 |
| 目标 | 一个需要持续多轮推进的目标 | 全部工具；每轮结束调用 `goal_report`，按上限自动续跑 |
| 创造 | 生成文档、代码、技能、插件 | 全部工具；先列交付物与路径，再执行并自检 |

计划模式的运行结束后，对话末尾会出现「执行计划」。批准后模式切回普通模式，沿用同一份 transcript 继续执行。

目标模式在「模式」菜单里编辑目标。达到最大续跑轮数、状态变为 blocked 或被手动暂停时停止。自动续跑受 `goal_auto_continue`、`goal_max_iterations` 与每日预算约束。

## 上下文压缩

触发条件：

- `auto_compact` 开启，且当前 transcript 估算超过 `compact_threshold_percent`（默认 75%）；
- 或者点击标题栏的压缩按钮 / ⌘K「压缩上下文」。

压缩流程：

1. 只在用户消息处切分，避免产生孤立的 tool result；
2. 保留最近 `compact_keep_turns` 轮；
3. 把更早的对话交给当前模型生成摘要（`compact_max_tokens`）；
4. 新 transcript 以 `【此前对话摘要】` 开头，再接最近轮次；
5. 摘要失败时直接截断旧轮次，并在对话里标记。

压缩会改变一次前缀缓存，这是预期行为；摘要前缀建立后，后续请求继续稳定命中。完整的 Agent transcript 保存在 `~/.config/myna/transcripts/<会话 id>.json`，重启/切换会话不会退化为纯文本。

## 附件

输入栏回形针或直接拖入窗口，可附加文件与文件夹。

- 文本文件（≤256KB/个）会内联到提示词，总量受 `attachment_inline_chars` 限制；
- 文件夹只生成浅层清单（深度 ≤2、最多 200 项），不递归读取；
- 图片只给路径，由模型调用 `view_image`；
- 路径失效会在附件块中标记，不阻断发送。

## 权限

「设置 → 权限」集中管理：

- 系统权限：辅助功能、屏幕录制、麦克风、语音识别、通知；
- 工具权限：每个工具可选 允许 / 询问 / 拒绝；可一键切换只读、标准、完全信任。

默认规则：

- 只读工具允许；
- 写文件、命令、AppleScript、鼠标键盘、打开应用/网址、自我修改、MCP、子代理询问；
- `disabled_tools` 始终拒绝；
- 计划模式强制只读，优先于工具权限。

授权弹窗支持「允许一次 / 始终允许 / 拒绝」；超时（默认 120 秒）按拒绝处理。非交互的 CLI 环境无法弹窗，询问类工具直接拒绝。

## 缓存与成本

- 模式变化会重建 Agent（保留 transcript），这是预期行为；
- 压缩会一次性改变前缀，之后保持稳定；
- 摘要请求计入当日 token 预算与费用保护；
- 保留全部历史会让上下文变大，必要时用压缩或新建会话。
