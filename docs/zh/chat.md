# 聊天与消息操作

[返回主文档](../../README.zh-CN.md) · [配置项全表](config.md)

Myna 的聊天窗口把每条用户 / 助手消息渲染成气泡，并提供消息级操作与代码高亮。

## 消息操作

每条**用户 / 助手**消息（思考、工具调用等可折叠区块除外）都支持以下操作。悬停到消息行时，气泡外侧会淡入一条紧凑的操作条；右键菜单提供同样的入口。

| 操作 | 适用角色 | 行为 |
|---|---|---|
| **复制** | 用户 / 助手 | 复制整条消息文本，图标短暂变为勾号作为反馈 |
| **重发** | 用户 / 助手 | 用户消息：截断到该消息之前并重新发送同样的文本；助手消息：截断到其前一条用户消息之前并重新生成回答 |
| **编辑并重发** | 仅用户 | 气泡就地切换为内联编辑器（预填原文），⌘↩ 保存并重发，Esc 取消 |

运行中（该会话 `busy`）时，重发与编辑按钮会禁用并显示提示。

### 截断语义

「重发」「编辑并重发」都会先把会话截断到目标消息之前，再重建运行上下文后发送：

- **内置运行时**：用截断后的气泡重建 `BuiltinAgent` 的消息历史，因此不会带着旧历史再次请求。
- **Swift 包运行时**：把截断后的会话映射为消息列表，通过 `Agent.setTranscript` 重建 transcript，再调用 `prompt`。
- 截断同时清理该会话的流式 / 思考状态并持久化会话。

由于操作作用于会话自己的运行上下文（而不是界面镜像），对**后台会话**的消息同样有效。被删除轮次里的信息不会再被模型记住。

## 代码块

助手回复中的围栏代码块（三反引号）会：

- 在顶部显示识别到的**语言名**；围栏没有语言信息时显示「代码」；
- 右上角提供**复制**按钮，复制**原始代码**（不含语言标签），点击后短暂显示「已复制」；
- 按语言做**语法高亮**，正文可选择，长行自动换行，空代码块也不会撑破布局；
- 在流式输出过程中实时高亮。

### 支持的语言

Swift、JavaScript / TypeScript（`js` / `jsx` / `ts` / `tsx`）、Python（`py`）、JSON、Shell（`sh` / `bash` / `zsh`）、Go、Rust（`rs`）、Java、C、C++（`c++` / `cc`）、Objective-C（`objc` / `objective-c`）、HTML / XML、CSS、SQL、YAML（`yml`）、Markdown（`md`）、Ruby（`rb`）、PHP、Kotlin（`kt`）。无法识别时按通用规则处理。

词法类别包括：注释（`//`、`#`、`/* */`、`--`、`<!-- -->` 等）、字符串（含前缀与转义）、数字、关键字、类型 / 内置名、函数调用与普通文本。明暗外观各有一套配色，定义在 `Theme.swift` 中。

### 不变式与自检

高亮器是 `Sources/Myna/SyntaxHighlight.swift` 中的纯函数令牌器，**无第三方依赖**。它保证：

```
String(highlight(code).characters) == code
```

即高亮结果去掉属性后与原文本逐字符一致；一旦不一致会安全回退为纯文本。可用隐藏命令自检：

```sh
myna highlight swift  file.swift          # 校验并打印识别结果
echo 'let x = "a" // c' | myna highlight swift -
myna highlight python file.py --dump      # 输出每个词法区间
```

退出码非零表示往返不一致。该命令不访问网络，可对任意语料批量运行。
